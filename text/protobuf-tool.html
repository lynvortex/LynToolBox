📦 功能说明

      
使用 protobufjs 在浏览器本地解析 .proto 定义，实现 JSON 与 Protobuf 二进制的相互转换，支持 Base64 与 Hex 两种二进制文本表示，便于调试与传输。

      

        .proto解析
        JSON转二进制
        二进制转JSON
        Base64
        Hex
        离线本地
      

    

    

      
💡 使用须知

      
    
        
  • 需先在上方输入 .proto 定义并点击「解析 Schema」以加载类型
    • 
        
  • 编码前会调用 verify 校验数据，字段类型不符会给出提示
    • 
        
  • 解码时自动识别 Base64 与 Hex 格式，也可手动指定
    • 
        
  • 支持 proto3 语法，含 message、enum、嵌套类型与 package
    • 
        
  • 所有编解码在本地完成，数据不会上传
    •
