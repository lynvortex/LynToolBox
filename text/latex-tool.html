📦 功能说明

使用 KaTeX 在浏览器本地实时渲染 LaTeX 数学公式，支持行内与展示两种模式切换，可一键复制渲染后的 HTML 片段用于网页嵌入。

实时渲染 行内模式 展示模式 复制HTML KaTeX 离线本地

💡 使用须知

  • 展示模式公式居中独占一行，行内模式公式嵌入文本流
  • 无需输入 $ 或 $$ 定界符，工具会按所选模式自动渲染
  • 支持分数 \frac、根号 \sqrt、上下标 ^_、希腊字母 \alpha 等
  • 复制 HTML 可直接粘贴到网页中（需页面已引入 KaTeX 样式）
  • 所有渲染在本地完成，公式内容不会上传
