📦 功能说明

      
使用 acorn 解析器将 JavaScript 代码解析为抽象语法树（AST），提供可折叠的树形视图与格式化 JSON 两种查看方式，并统计节点数量、代码行数与解析耗时。

💡 使用须知

      
    
        
  • 使用 ecmaVersion: latest、sourceType: module 解析，支持最新语法
    • 
        
  • 树形视图节点可点击折叠/展开，叶子节点显示原始值
    • 
        
  • 位置信息（loc）展示每个节点的起止行列位置
    • 
        
  • 代码有语法错误时会显示错误位置与提示信息
    • 
        
  • 解析在本地完成，代码不会上传到任何服务器
