📦 功能说明

左侧输入 HTML/CSS 代码，右侧实时预览，使用 html2canvas 将预览内容渲染为 Canvas 并导出 PNG 图片，可自定义缩放倍数与背景色。

DOM转图片 PNG下载 自定义尺寸 背景色 HTML预览 离线本地

💡 使用须知

  • 支持输入任意 HTML 片段，可包含内联 style 样式
  • 缩放倍数越高图片越清晰，但渲染耗时增加
  • html2canvas 对跨域图片有同源策略限制，请使用本地或同源图片
  • 部分 CSS 特性（如 backdrop-filter、部分伪元素）可能无法完美还原
  • 所有渲染在浏览器本地完成，不上传任何内容
