📦 功能说明

基于 PapaParse 解析 CSV/TSV 数据，支持自动识别分隔符、表头识别、跳过空行，解析后以表格预览前 100 行并显示行列统计，可导出 JSON 或 CSV。

CSV解析 TSV支持 自动分隔符 表头识别 JSON导出 大文件流式

💡 使用须知

  • 支持上传文件或直接粘贴文本两种输入方式
  • 分隔符可选自动识别或手动指定（逗号/制表符/分号/竖线/自定义）
  • 大文件采用流式解析，预览仅显示前 100 行，导出包含全部数据
  • 导出 JSON 为数组格式（表头模式为对象数组，否则为二维数组）
  • 所有解析在浏览器本地完成，不上传任何文件
