📦 离线版

绘萤工具箱 · 命令行版（LynToolBox-cli）

精选工具箱中的编程开发与开发者实用功能，打包为单文件 exe，在命令提示符（CMD/PowerShell/Terminal）中直接运行。

无需安装任何运行环境，不依赖浏览器，断网可用，数据全部留在本机。

⬇️ 下载最新 exe（Windows） 📋 查看全部版本

🚀 使用方法

  • 从 Releases 页面 下载 lyntoolbox-cli.exe，放到任意目录；
  • 打开命令提示符，切换到该目录，运行 lyntoolbox-cli.exe --help 查看全部可用命令；
  • 也可将 exe 所在目录加入 PATH 环境变量，在任意位置直接调用。
