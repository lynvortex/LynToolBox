URL 编码说明

URL 编码（Percent-encoding）将非 ASCII 字符和特殊字符转换为 % 后跟两位十六进制数的格式，确保 URL 在网络上安全传输。

encodeURIComponent decodeURIComponent 百分号编码 UTF-8

使用须知

  • 编码使用 encodeURIComponent()，对包括特殊字符在内的所有非字母数字字符进行编码
  • 解码使用 decodeURIComponent()，将百分号编码还原为原始字符
  • 适用于 URL 查询参数、表单提交等场景的编码需求
  • 所有操作在浏览器本地完成，数据不会上传到服务器
