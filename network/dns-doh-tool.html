📦 功能说明

纯前端通过 DNS over HTTPS（DoH）协议查询 DNS 记录，支持 Cloudflare 与 Google 双服务商切换，可查询 A/AAAA/MX/TXT/NS/CNAME/SOA/CAA 等记录类型，并支持每行一个域名批量查询。

A记录 AAAA MX TXT NS CNAME 双DoH源 批量查询

💡 使用须知

  • 纯前端直连 DoH 端点，请求不经过自有服务器，查询在你的浏览器完成
  • Cloudflare 与 Google 的 DoH JSON 端点均支持 CORS，可直接跨域调用
  • TTL 单位为秒，表示记录在解析器缓存中的有效时长
  • 批量查询时每行一个域名，结果按域名分组展示
  • 若查询失败可尝试切换另一个 DoH 服务商后重试
