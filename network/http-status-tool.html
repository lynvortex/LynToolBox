状态码分类

HTTP 状态码由三位数字组成，首位数字表示响应类别：

1xx 信息 2xx 成功 3xx 重定向 4xx 客户端错误 5xx 服务端错误

使用须知

  • 在搜索框中输入编号或名称可快速定位
  • 数据覆盖常见的 HTTP 标准状态码，包括 RFC 文档定义
