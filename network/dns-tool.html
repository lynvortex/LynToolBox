📡 实现原理

利用 Google Public DNS 的 HTTPS 接口，在浏览器端直接完成 PTR 查询，不再需要自建代理服务器。

DNS-over-HTTPS PTR 记录 公共 DNS

💡 使用须知

  • 输入 公网 IPv4 地址（例如 8.8.8.8）即可反查
  • 结果取决于该 IP 的运营商是否配置了 PTR 记录
  • 查询请求直接发往 Google DNS，不会经过我们的服务器
  • 如果需要正向解析（域名→IP），同样可以采用 DoH 方式实现
