📦 功能说明

纯前端校验 IPv4/IPv6 地址合法性，解析各段十进制与二进制；带 CIDR 时计算网络地址、广播地址、子网掩码、可用主机范围与地址总数；并支持判断某 IP 是否属于指定网段。

IPv4校验 IPv6校验 CIDR解析 子网范围 网段判断 离线本地

💡 使用须知

  • 所有校验与计算均在浏览器本地完成，数据不上传
  • 解析能力基于 ipaddr.js（开源库），同时支持 IPv4 与 IPv6
  • CIDR 格式如 192.168.1.0/24，前缀长度 IPv4 为 0-32、IPv6 为 0-128
  • IPv4 子网可用主机数已扣除网络地址与广播地址（/31、/32 按特殊规则）
  • IPv6 理论上所有地址均可分配，结果中的「末地址」即网段最大地址
