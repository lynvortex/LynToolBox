📦 功能说明

基于浏览器原生 Web Serial API，无需安装驱动或插件，直接在网页中选择本地串口设备，配合 xterm.js 终端进行实时收发调试，支持波特率、数据位、停止位、校验位与换行符配置。

Web Serial xterm终端 波特率设置 收发调试 自动回显 本地通信

💡 使用须知

  • 仅 Chrome / Edge 等基于 Chromium 的浏览器支持 Web Serial API
  • 页面需通过 HTTPS 或 localhost 访问，否则 API 不可用
  • 连接时需用户手动在系统弹窗中选择并授权对应的串口设备
  • 断开前请先点击「断开」以正确释放串口资源，避免被占用
  • 所有数据在浏览器与本地设备间直传，不经过任何服务器
