子网计算说明

CIDR（无类域间路由）表示法以 IP 地址后跟斜杠和前缀长度表示子网。

CIDR 网络地址 广播地址 子网掩码

使用须知

  • 输入格式为 IP地址/前缀长度，例如 192.168.1.0/24
  • 前缀长度范围 0-32（IPv4）
  • 结果将显示网络地址、广播地址、子网掩码、可用 IP 范围及数量
  • 同时显示各地址的十进制和二进制对照
  • 所有计算在浏览器本地完成，数据不会上传
