RSA 密钥说明

基于 Web Crypto API 实现，所有密钥对在浏览器本地生成，不会上传到服务器

RSA-OAEP RSASSA-PKCS1-v1_5 Crypto API PEM 格式

使用须知

  • 密钥生成在浏览器本地完成，不经过任何网络传输，请放心使用
  • 1024 位已不再安全，仅建议用于测试场景
  • 2048 位是目前广泛接受的安全标准，兼顾安全与性能
  • 4096 位提供更高安全性，但生成和加解密速度较慢
  • 生成的密钥为 PEM 格式，可直接用于 OpenSSL、SSH 等工具
  • 请妥善保管私钥，切勿泄露给他人
