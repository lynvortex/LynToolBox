💡 使用须知

  • 所有计算在浏览器本地完成，文件不上传服务器
  • 支持拖拽上传或点击选择文件
  • 文件在浏览器内存中计算，超200MB大文件可能需要等待
  • 可填入已知哈希值自动校验文件完整性
