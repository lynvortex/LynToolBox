JWT 结构说明

JSON Web Token 由三部分构成：Header（头部）.Payload（载荷）.Signature（签名）

Header Payload Signature Base64URL 纯前端

使用须知

  • Header：包含令牌类型（typ）和签名算法（alg）等信息
  • Payload：包含声明（claims），如 iss（签发者）、sub（主题）、exp（过期时间）等
  • Signature：用于验证令牌未被篡改，本工具仅解码显示，不验证签名有效性
  • 所有解码在浏览器本地完成，Token 不会发送到任何服务器
  • 支持复制各部分内容，方便调试和开发
