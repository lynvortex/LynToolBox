HMAC 算法说明

基于哈希的消息认证码，结合密钥对消息进行签名，验证数据完整性和来源真实性

HMAC-SHA1 HMAC-SHA256 HMAC-SHA512 Web Crypto API

使用须知

  • SHA-1：160 位输出，已不推荐用于安全敏感场景
  • SHA-256：256 位输出，目前最常用的 HMAC 算法，推荐使用
  • SHA-512：512 位输出，安全性最高，但输出长度也最长
  • HMAC 签名常用于 API 认证、JWT 签名、数据完整性校验等场景
  • 所有运算在浏览器本地完成，密钥和消息不会离开您的设备
  • 支持 Hex 和 Base64 两种格式输出，方便直接复制使用
