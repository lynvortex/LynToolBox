📦 功能说明

基于 bignumber.js v9 在浏览器本地进行任意精度数值运算，彻底规避 JavaScript 浮点误差（如 0.1+0.2），支持加减乘除、取模、幂、开方，并提供大数阶乘与 Miller-Rabin 素数判定扩展。

任意精度加减乘除取模幂运算无浮点误差格式化输出离线本地

💡 使用须知

  • 除法与开方结果按设定的精度位数舍入（默认 20 位，四舍五入）。
  • 幂运算指数需为整数，过大指数可能产生极长结果，请合理使用。
  • 阶乘建议 N ≤ 10000，过大会导致计算缓慢。
  • 素数判定采用 Miller-Rabin 概率性算法，对超大整数高效可靠。
  • 所有运算在浏览器本地完成，数据不上传。
