📦 功能说明

基于 Ajv 在浏览器本地校验 JSON 数据是否符合指定的 JSON Schema 规范，开启 allErrors 模式列出全部错误，每条错误标注数据路径、关键字与详细原因。

💡 使用须知

  • 左侧填写 JSON Schema（draft-07 规范），右侧填写待校验的 JSON 数据。
  • 错误路径使用 JSON Pointer 格式，如 /age 表示根对象的 age 字段，/0/name 表示数组首项。
  • 关键字（keyword）标明违反的约束，如 type、required、minimum、maxLength 等。
  • 本工具内置 Ajv v6，不校验 format 关键字（如 email/uri）的格式细节，仅校验结构约束。
  • 所有校验在浏览器本地完成，数据不会上传。
